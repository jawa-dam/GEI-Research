# MCT Starter Dataset — V1.0.3

This directory contains the first machine-readable records for the GEI Master Chronology & Taxonomy (MCT).

## Starter scope

V1.0.3 establishes an initial cross-domain dataset covering chronology, civilizations, regions, texts, cosmology, water systems, comparisons, GEI interpretations, GEI hypotheses, and sources.

## Dataset rule

These records are intentionally conservative. A record describes its source or tradition before making an interpretive claim. Comparisons are labeled as comparisons, and GEI interpretations/hypotheses are explicitly marked as such.

## Status

**MCT Starter Dataset: V1.0.3 — initial structured release**

The dataset will expand after the validation layer is operational. Missing source IDs or empty relationship arrays are intentional where source-level documentation has not yet been loaded.
